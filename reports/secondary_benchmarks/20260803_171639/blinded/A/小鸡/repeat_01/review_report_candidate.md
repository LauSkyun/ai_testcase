## 二、逐维度问题清单
### 【清晰度与完整性】
- **[严重程度：高] 难度系统概率模型、包装与UI风险展示的多重冲突**
  - 现状描述：1、1. 概率模型冲突：需求文档「小鸡.docx / 3.1 下注系统，表格2」给出简单难度固定概率（20%、35%、50%、65%），但数值文档「小鸡数值文档.docx / 4. 撞击概率计算」采用 Crash 算法（首次必撞3%，非首次1%），且缺失中等、困难、极限难度的具体概率配置。；2、2. 美术包装不一致：需求文档「小鸡.docx / 4、题材包装」定义核心形象为卡通骆驼，但所有 UI 截图（图片1-8）及游戏标题均为“CHICKEN ROAD”，角色为白色小鸡；3、需求文档段落55说明“一开始美术可先用默认小鸡形象”，但并未明确后续切换计划与玩家认知影响。；4、3. UI 风险展示缺失：UI 截图中标有“被击中的概率”标签，但文档未定义该概率值的计算公式，未说明是固定值、动态值还是 Crash 算法期望值，测试无法验收 UI 与真实概率的一致性。
  - 证据来源：小鸡.docx / 3.1 下注系统，表格2；小鸡数值文档.docx / 4. 撞击概率计算，段落11-17；小鸡.docx / 4、题材包装，段落55-56；UI截图解析（图片1-8）。

  - 置信度：高
  - 阻塞级别：阻塞测试用例设计

  - 证据来源：小鸡.docx / 3.3 奖金计算系统，段落44；小鸡数值文档.docx / 3. 难度选择，表格2；小鸡数值文档.docx / 4. 撞击概率计算，表格3。
