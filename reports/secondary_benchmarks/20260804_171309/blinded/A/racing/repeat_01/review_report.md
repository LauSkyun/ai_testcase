# 需求文档分析报告

## 一、总体评价
文档整体描述了Racing玩法的核心循环、干预逻辑与UI交互，但核心结算链路存在严重的公式冲突与变量定义歧义，且关键控盘参数缺失具体数值。主流程在概念上可理解，但直接用于开发会导致结算逻辑无法实现或产生资金风险。

- **文档质量评分：** C
- **评分原因：** 核心赔率公式在需求与数值文档中存在根本性冲突，T变量定义矛盾，且干预逻辑缺乏到速度公式的具体映射，导致结算链路无法落地，需补充对齐后再开工。

## 优先处理事项
- **[高] 开奖时间T与赔率公式中的T变量定义冲突，导致公式无法求值**
  - 责任建议：数值策划
  - 处理原因：变量定义歧义导致赔率公式无法正确编码，结算结果不可预期。；结算精度规则不清，可能导致平台抽水失效或用户赔付金额计算错误。；两套公式逻辑完全不同，开发无法确定使用哪套进行结算，直接阻塞核心结算链路。；该问题可能导致开发、配置或测试对“赔率计算模型在需求与数值文档中存在根本性冲突”采用不一致口径。；该问题可能导致开发、配置或测试对“开奖时间T与赔率公式中的T变量定义跨文档冲突”采用不一致口径。
- **[高] 假人数/假金额参与实时赔率计算会导致赔率失真，数据源隔离规则缺失**
  - 责任建议：系统策划
  - 处理原因：若假数据参与赔率计算，会导致真实用户的赔率被虚假繁荣稀释或扭曲，引发严重客诉。
- **[高] “实际赔率”与“假赔率”的客户端展示与服务端结算映射缺失**
  - 责任建议：系统策划
  - 处理原因：若展示假赔率而结算用实际赔率，会导致用户看到的预期收益与实际到账不符，引发严重客诉。；该问题可能导致开发、配置或测试对““实际赔率”与“假赔率”的展示与结算映射跨文档缺失”采用不一致口径。

### 【逻辑一致性与数值平衡】
- **[严重程度：高] 开奖时间T与赔率公式中的T变量定义冲突，导致公式无法求值**
  - 现状描述：1、需求文档中T定义为“实际消耗的秒数（完成时间）”，而数值文档赔率公式中T作为分子参与计算，若T为耗时，则耗时越长赔率越高，违背常理；2、若T为总下注额，则与需求文档定义冲突。；3、需求文档要求实时赔率“保留两位小数，向下取整”，表述存在逻辑矛盾。同时数值文档规定最低赔率1.02，若按整数向下取整则变为1.00。；4、需求文档定义实时赔率为“合计下注/本选项下注*系数”，而数值文档定义为“Odds_X = (T*(1-r)/W_X)*γ”。；5、需求文档定义实时赔率为基于资金池比例的公式（合计下注/本选项下注），而数值文档定义为基于权重与膨胀系数的公式（Odds_X = (T*(1-r)/W_X)*γ）。两者逻辑完全不同，导致开发无法确定最终结算链路。
  - 证据来源：musee游戏Racing.docx / 3.4开奖逻辑 段落36及图片13；Racing数值文档.docx / 图片1；musee游戏Racing.docx / 3.3下注部分 段落28；Racing数值文档.docx / 段落2；musee游戏Racing.docx / 3.3下注部分 段落28；Racing数值文档.docx / 图片1；['musee游戏Racing.docx / 3.3下注部分 段落28', 'Racing数值文档.docx / 图片1']；['musee游戏Racing.docx / 3.4开奖逻辑 段落36及图片13', 'Racing数值文档.docx / 图片1']
  - 风险分析：1、变量定义歧义导致赔率公式无法正确编码，结算结果不可预期。；2、结算精度规则不清，可能导致平台抽水失效或用户赔付金额计算错误。；3、两套公式逻辑完全不同，开发无法确定使用哪套进行结算，直接阻塞核心结算链路。；4、该问题可能导致开发、配置或测试对“赔率计算模型在需求与数值文档中存在根本性冲突”采用不一致口径。；5、该问题可能导致开发、配置或测试对“开奖时间T与赔率公式中的T变量定义跨文档冲突”采用不一致口径。
  - 修改建议：1、重新定义赔率公式中的变量，明确T的物理意义（如总下注额、总权重等），并与开奖时间公式中的T区分命名。；2、明确取整规则，如“保留两位小数，第三位四舍五入”或“赔付金额向下取整到整数”。明确最低赔率1.02是否参与取整逻辑。；3、明确统一赔率计算公式。若为资金池模式，需补充r、W_X、γ的定义；4、若为数值文档公式，需修改需求文档中的赔率描述。；5、数值策划与系统策划需对齐并统一赔率计算模型，明确最终采用的公式及所有变量的物理意义。
  - 关注角色：数值策划
  - 置信度：高
  - 阻塞级别：阻塞开发
- **[严重程度：高] “干扰指数”与“地形概率”缺乏到速度公式的具体映射，干预逻辑无法落地**
  - 现状描述：需求文档提到通过调整“干扰指数”和“隐藏地形概率”来干预开奖，但未说明干扰指数如何作用于速度公式 T = L / (V * K * Luck) 中的具体变量。
