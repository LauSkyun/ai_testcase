  - 证据来源：musee游戏Racing.docx / 段落28；Racing数值文档.docx / 段落2-5、图片1-2；Racing数值文档.docx / 段落5；musee游戏Racing.docx / 段落28；Racing数值文档.docx / 段落5 提到“分实际赔率和假赔率”；musee游戏Racing.docx / 段落28 仅规定实时赔率直接用于赔付，无假赔率概念。；musee游戏Racing.docx / 段落28 定义实时赔率 = 合计下注 / 本选项下注 * [001]%；Racing数值文档.docx / 段落2-5 及图片1 定义 odds = max( T*(1-x)/W, 1.02 )，并引入 gamma 系数；需求文档中 T 为完成时间，数值文档中 T 可能为总下注。；musee游戏Racing.docx / 段落28；Racing数值文档.docx / 图片1
